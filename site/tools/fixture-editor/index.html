Schema-driven · browser-local · review-only

Edit a fixture without confusing a proposal with product truth.

The editor loads the published canonical fixture and JSON Schema, validates changes in the browser, and downloads a proposed JSON revision. It never writes to GitHub or upgrades engineering authority.

Authority boundary

Schema valid does not mean engineering approved, manufacturing released, structurally verified, photometrically approved, or construction ready.

Repository review, controlled hashes, invariant checks, physical qualification, and applicable release gates remain authoritative.
