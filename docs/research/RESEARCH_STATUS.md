Historical research baseline, updated for repository reality on 2026-09-10.

The first open-source landscape pass is complete. This document originally described work that had not yet landed; the implementation status below distinguishes shipped foundations from still-open evidence work.

Completed:

- relevance and licence classifications recorded.
- first/second/later implementation tiers defined.
- canonical AETHERIA fixture-platform architecture established.
- third-party licence policy proposed.
- versioned JSON Schema contracts created.

- deterministic product/viewer generation and repository validation implemented.
- IFC coordination export implemented as a derived adapter, with explicit authority/loss boundaries.

Still open or evidence-gated:

- GDTF/MVR output remains blocked until the controlled head, control and aiming dependencies required by the interchange loss policy are released.
- permissive-dependency and licence boundaries must remain enforced as further external tooling is adopted.
- physical engineering, certification and manufacturing evidence remains authoritative outside presentation and coordination adapters where documented.

For current implementation priorities, use `ROADMAP.md`, the open GitHub issues, and the repository-intelligence/authority documentation rather than treating this research snapshot as the live backlog.
