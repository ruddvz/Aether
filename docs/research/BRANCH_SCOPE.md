# Branch scope

Branch: `research/open-source-lighting-stack`

Purpose: establish the open-source research baseline, canonical fixture-data direction, license policy and draft AETHERIA fixture schema.

This branch intentionally does not:

- add runtime dependencies.
- change the current public VORTEX HTML.
- claim real photometric validation.
- create IFC/GDTF/MVR exports.
- add DMX/network control.

Those belong in follow-up implementation work after the fixture manifest and validator are stable.
