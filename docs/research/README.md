# AETHERIA open-source research

This directory records evaluated external projects and the decisions that follow from them.

Start here:

- `OPEN_SOURCE_LIGHTING_LANDSCAPE.md` for the scored repository audit.
- `IMPLEMENTATION_PRIORITY.md` for the execution order.
- `../architecture/AETHER_FIXTURE_PLATFORM_PLAN.md` for the proposed platform architecture.
- `../architecture/THIRD_PARTY_POLICY.md` for dependency and license rules.

Research does not mean automatic adoption. Every third-party dependency still needs a pinned version, purpose, license review and reproducible integration before it becomes part of a release.
