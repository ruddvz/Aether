# GitHub Pages

The Pages site is generated by `scripts/build_site.py`.

Public routes:

- `/Aether/` generated AETHERIA catalog
- `/Aether/products/vx4800/` current approved VORTEX presentation
- `/Aether/products/vx4800/versions/5.2.0/` immutable presentation route
- `/Aether/downloads/vx4800/5.2.0/AETHERIA_VORTEX_v5.2.0.zip` reproducible release package

The root catalog is registry-driven so adding another fixture does not require replacing the site architecture.

Pages deploys only after canonical validation, geometry QA, regression tests and a successful site build.
