# VX4800 photometry candidates

These records are controlled supplier-research inputs, not approved luminaires.

Rules:

- Unknown exact values are `null`. Never use placeholder model, optic, CCT, CRI, driver or photometry data to satisfy a schema.
- `shortlisted` means the family remains worth supplier qualification. It does not override evaluator blockers.
- `photometryStatus: linked` means an official URL is known but the raw file has not been controlled, hashed and parsed.
- `downloaded`, `parsed` and `verified` require the exact raw file, matching configuration and SHA-256 provenance.
- Family-level data must not be promoted to an exact configuration unless the manufacturer maps it explicitly.
- Historical brochures may inform questions but do not establish a current exact configuration.
