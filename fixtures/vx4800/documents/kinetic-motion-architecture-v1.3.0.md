# VX4800 Kinetic Motion Architecture v1.3.0

## Fixed system
- site structural interface
- primary internal frame
- outer canopy shell
- stationary trim ring
- 14 LED accent heads
- upper bearing support
- motor mount and guarding
- controller, isolator and service access

## Rotating system
- lower bearing interface
- elliptical carrier plate
- 240 cable exits
- 240 suspension cables
- 240 anti-rotation yokes
- 240 optical butterflies
- balance provisions

All LED heads stay fixed, so this concept does not require an electrical slip ring.

Viewer default motion: 0.35 rpm. Viewer range: 0.10 to 0.60 rpm. These are visualization settings, not a released physical operating envelope.

A real 4.8 m suspended field must be tested for pendulum lag, aerodynamic drag, transient cable angles, dynamic element clearance, vibration, torsional oscillation, imbalance, motor torque/braking demand, noise and long-term wear.

Before occupied-space installation, the complete rotor load path, independent retention, bearing, drive, home/position reference, jam detection, controlled restart, service lockout, emergency stop, full factory pre-hang, endurance and fault testing must be engineered and validated. No generic site anchors are released by this package.
